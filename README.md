# ABHISHEK.exe — Spidey pixel portfolio (React + Tailwind + Framer Motion)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

- **Edit your content:** `src/data.js` (name, bio, projects, skills, experience, contact placeholders)
- **Resume button:** put your PDF at `public/resume.pdf`
- **Settings (gear icon):** dark/light mode, sound effects, Miles theme — saved in localStorage
- **Colors:** CSS variables at the top of `src/index.css`
